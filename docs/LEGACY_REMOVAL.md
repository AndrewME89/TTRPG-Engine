# Legacy Removal Notes

## Removed / must not return

- Old random SVG map generator UI.
- Generate/regenerate SVG map controls.
- Old map generator commands.
- Hardcoded fantasy skinning as the default plugin style.

## Preserved compatibility

The current Tile Map Builder still supports legacy emoji-only tile data so old saved maps do not break. This is acceptable because it is compatibility, not the old map generator returning from the grave wearing a fake moustache.

## Current map standard

The plugin uses the Tile Map Builder only.
